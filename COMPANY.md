# Agent Company

This repository is organized as an agent company with department-level source
plugins and a shared project runtime for Claude, Codex, Cursor, OpenClaw, and
other agents that read `.agents`.

## Company Shape

- `system`: plugins management, skill evaluation, memory, knowledge base, brain ingestion, personalization, and loops
- `marketing`: content, discoverability, social, slides, video, images, and visualization
- `sales`: prospecting, outreach, GTM, pipeline support
- `engineering`: architecture, implementation, QA, security, docs, cloud
- `product`: product development, product marketing, and design
- `finances`: expenses, reconciliation, planning, taxes, fundraising, fiscal close, and analysis
- `productivity`: reporting, research, review, documentation drift, and operational cadence

## Agent Model

Every plugin skill is reachable through at least one same-plugin agent. Strategy,
orchestration, execution, research, and review remain separate workflow lanes;
headcount is expressed by spawning reusable role agents rather than copying files.
The current coverage matrix is generated by `python3 scripts/audit_agents.py .`.

## Teams

- CEO + Executive Assistant
- CTO + Cloud Architect + Software Engineer x3 + Product Manager + Designer + AI Engineer
- CSO + GTM Engineers x2 + SDR x3 + Account Executive x2
- CFO + Financial Analyst + Accountant

## Installation Model

- The preferred first-party command installs whole plugins or individual
  elements into `.agents/{skills,commands,rules,agents}` in the target project.
- Installed elements from multiple plugins share those four namespaces; plugin
  names remain lockfile provenance rather than runtime folders.
- Claude's marketplace and Codex/Cursor department directories remain supported
  secondary runtime-native and development surfaces.
- The full repository is the canonical company package and coordination layer.
- See [`references/docs/INSTALLATION.md`](references/docs/INSTALLATION.md) for
  all supported installation methods and safe update behavior.
