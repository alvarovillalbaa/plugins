# Scripts

| Script | Purpose |
|--------|---------|
| `experiment-engine.py` | Core experiment lifecycle: create, log, score, list, playbook, suggest |
| `autogrowth-weekly-scorecard.py` | Weekly report across all agents/channels |
| `requirements.txt` | Python dependencies (`numpy`, `scipy`) |
| `.env.example` | Environment variable template — copy to `.env` before first run |

Run `pip install -r requirements.txt` before first use.
