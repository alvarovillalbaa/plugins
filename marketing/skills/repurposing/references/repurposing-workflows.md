# Repurposing Workflows Reference

Reference for turning one source asset into channel-specific posts, newsletters, articles, and distribution packs. Repurposing ≠ copy-paste: each channel gets an *adapted* version that respects its format, audience, and norms. Pull voice and channel facts from repo-local docs.

## Why repurpose

One substantial asset (a blog post, webinar, report, podcast) contains 10+ pieces of derivative content. Repurposing multiplies reach without multiplying source work, reinforces a message through repetition across channels, and meets audiences where they already are. The rule of thumb: **create once, distribute everywhere, adapt each time.**

## The atomic-content model

Break the source into reusable atoms, then recompose per channel:
- **Core thesis** → the one-line claim.
- **Key points** (3–7) → each becomes a post, slide, or section.
- **Stats / data** → each becomes a graphic or a tweet.
- **Quotes / soundbites** → each becomes a pull-quote card or DM hook.
- **Stories / examples** → each becomes a narrative post.
- **Steps / framework** → becomes a carousel or thread.

## Source → channel map

| Source | Repurpose into |
| --- | --- |
| **Blog post / article** | LinkedIn post + carousel, X thread, newsletter section, 3–5 short social posts, quote graphics, FAQ entries |
| **Webinar / talk** | Article recap, clip reels, key-slide carousel, quote cards, X thread of takeaways, email follow-up |
| **Podcast episode** | Audiogram clips, quote cards, X thread, show-notes article, newsletter feature |
| **Research / report** | Stat graphics, "key findings" carousel, summary post, gated → ungated teaser, press/PR angle |
| **Customer story / case study** | Testimonial post, results graphic, sales one-pager (→ `sales` collateral), narrative LinkedIn post |
| **Internal doc / FAQ** | Help article (→ `context-to-content`), social explainer, onboarding email |
| **Newsletter** | Individual social posts per section, archive blog post |

## Adapt, don't duplicate

For each target channel, transform along these axes:
- **Length** — trim a 1,500-word post to a 200-word LinkedIn post or a 280-char hook.
- **Format** — prose → carousel slides, list → thread, data → graphic.
- **Hook** — rewrite the opening for the channel's scroll behavior (see channel guides).
- **Tone** — LinkedIn (professional), X (punchy/casual), newsletter (intimate).
- **CTA** — match the channel (comment on LinkedIn, reply on X, click in newsletter).
- **Framing** — lead with the angle that resonates on that platform.

Never post the identical text across channels — audiences overlap and it reads lazy, and platforms can suppress duplicate/cross-posted content.

## Workflow

1. **Pick the pillar asset** — the deepest, most valuable source.
2. **Extract atoms** — list every reusable point, stat, quote, and story.
3. **Map atoms to channels** — decide what becomes what (use the table).
4. **Adapt each** — apply the channel's format, hook, length, and CTA. Route to the channel skill (`linkedin-posts`, `x-articles`, `syndication`, etc.).
5. **Sequence the rollout** — stagger over days/weeks so it doesn't all fire at once; let each piece point back to the pillar.
6. **Set canonical** — the pillar asset is the source of truth; cross-channel versions link/point to it (coordinate with `syndication` for canonical URLs).

## Distribution pack

A "distribution pack" is the bundle of repurposed assets for one source, ready to schedule:
- 1 pillar (the original).
- 2–3 LinkedIn posts + 1 carousel.
- 1 X thread + 3–5 standalone X posts.
- 1 newsletter section.
- 3–5 quote/stat graphics.
- 1 short-form video/clip script (if applicable).
- A posting schedule (which asset, which channel, which day).

## Sequencing & cadence

- **Don't dump** — spread a pack over 1–3 weeks. The same audience seeing 8 posts in a day is fatigue; seeing them over weeks is reinforcement.
- **Lead with the strongest atom**, save others to sustain momentum.
- **Re-promote evergreen pillars** every few months with a fresh hook — repurposing includes re-using your own back catalog.
- **Vary the angle** on re-promotion so it doesn't read as a repeat.

## Quality gates

- Each repurposed piece must **stand alone** — a reader who never saw the source still gets value.
- Preserve accuracy — don't let trimming distort a claim or strip a necessary caveat.
- Keep facts/stats true to the source; no drift introduced in adaptation.
- Match each channel's voice and format conventions, not the source's.
- Run derivative copy through `humanizing` so it doesn't read templated.

## Handoffs

- Channel-specific drafting → `linkedin-posts`, `linkedin-articles`, `x-posts`, `x-articles`.
- Cross-channel distribution + canonical URLs → `syndication`.
- Visuals → `images`, `slides`, `visualization`.
- Sales-facing versions → `sales` collateral.
