# slides skill

`slides` is an agent skill for building responsive, code-based slide decks and single-file HTML presentations with visual preset exploration, PPT-to-web conversion guidance, configurable navigation placement, multi-source image workflows, and AI-image slide generation from structured content specs.

## Portable use

Clone the repository or copy `skills/slides` into your local skill registry, then load `SKILL.md` in your preferred assistant environment.

## Repo-specific integration

Environment-specific install examples live in [references/docs/agent-company-integration.md](../../../../references/docs/agent-company-integration.md).

## Repository layout

- `skills/slides/SKILL.md`: Skill instructions and workflow.
- `skills/slides/agents/`: UI metadata for skill pickers and default prompts.
- `skills/slides/references/`: Decision trees, style presets, viewport-fit, and implementation references.
- `skills/slides/scripts/`: Scaffolding, image generation, indexing, validation, and install automation.
- `skills/slides/templates/`: HTML and React/TS starter templates.
- `skills/slides/templates/`: Planning and implementation prompt templates.
