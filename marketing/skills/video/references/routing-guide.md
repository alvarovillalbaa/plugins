# Video — Routing Guide

Router for video content production. Routes to video production specialist skills.

## Framework Routes

| Route | Owns |
|-------|------|
| external `hyperframes` | HyperFrames video composition and generation |
| external `remotion-best-practices` via registry key `remotion` | Programmatic video generation with React + Remotion |
| `slides` | Slide-based video (Loom-style, presentation recordings) |

## When to Use This Skill Directly

- Planning a video content strategy (format, cadence, distribution).
- Writing video scripts before production begins.
- Deciding which video format fits the use case.

## Video Format Decision Matrix

| Format | Use When | Tool |
|--------|----------|------|
| Programmatic animation | Data viz, product demos, branded sequences | remotion |
| Screen recording + voiceover | Tutorials, walkthroughs, Loom-style | slides |
| Slide-based presentation | Thought leadership, keynotes, webinars | slides |
| Short-form social video | LinkedIn/X clips, product teasers | remotion |

## Video Production Workflow

1. **Brief** — Define audience, goal, format, length, distribution channel.
2. **Script** — Write full script or bullet-point outline before production.
3. **Storyboard** — For animated/remotion videos, sketch key frames.
4. **Produce** — Generate or record with the appropriate official external framework skill or local cross-media skill.
5. **Review** — Check pacing, audio quality, brand consistency.
6. **Distribute** — Route to the appropriate platform via `syndication` or `social-media`.

## Video Standards

- **Captions always**: Add captions to all social videos — most are watched muted.
- **Hook in 3 seconds**: First 3 seconds must convey the value proposition.
- **Aspect ratios**: 16:9 for YouTube/presentations, 9:16 for Stories/Reels, 1:1 for feed posts.
- **Length targets**: Tutorial ≤ 10 min, social ≤ 60 sec, demo ≤ 3 min.
