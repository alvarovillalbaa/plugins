# Visual Directions

External owner boundary:

- Use `hallmark` for visual direction, theme selection, typography, palette, anti-slop review, responsive gates, and design-system token discipline.

This file only maps HTML-visual output modes to the kind of Hallmark direction to request.

| HTML visual mode | Hallmark request |
| --- | --- |
| explainer | default design flow with an educational/editorial artifact brief |
| review | audit-style hierarchy with evidence-first sections |
| comparison | data/editorial structure with clear contrast between options |
| dashboard or status page | product-mode restraint and dense scan paths |
| narrative report | editorial or document-like structure |

After Hallmark determines the visual system, keep HTML-visual responsible for the actual self-contained artifact, data wiring, and export constraints.
