# Productivity

Owns reporting, research, review, documentation drift, evidence-led personal growth, meetings, and executive operating workflows.

Route general coaching and growth experiments through `improve-me`; route only explicit roast requests to `roast-me` and explicit period-and-rubric self-reviews to `my-performance`. Use `meetings` for preparation, capture, closeout, recurring continuity, and multi-meeting portfolios.

Personal workflows use current context, already loaded memory, and repo-local memory by default. They require scoped approval before opening new private sources and separate approval before writing memory. Meeting workflows draft external actions by default and require confirmation before sending, scheduling, recording, or changing a calendar.
