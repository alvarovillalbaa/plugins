# Post-run Check

Before returning a performance review:

1. Confirm that role, period, rubric, scale, purpose, and audience are declared.
2. Confirm that each score meets the evidence-sufficiency rule and uses only in-period evidence.
3. Replace missing-coverage zeros with `not evaluated`.
4. Omit the overall score when weighted coverage is below 75%.
5. Separate facts, inferences, and trends and preserve contradictions.
6. Remove protected-trait, sensitive-trait, diagnosis, intent, and unsupported coworker-comparison claims.
7. Confirm that private-source reads and memory writes followed their separate approval gates.
