# Launches — Routing Guide

Router for product and feature launch coordination. Routes to execution skills.

## When to Use This Skill Directly

- Designing a launch plan (timeline, channels, stakeholders).
- Writing launch communications (email, press, social).
- Running a pre-launch readiness review.
- Post-launch analysis and retrospective.

## Launch Type Decision Matrix

| Launch Type | Primary Channels | Support Skills |
|------------|-----------------|----------------|
| New product | Press, email, social, Product Hunt | content, marketing |
| New feature | In-app, email, changelog | content |
| Pricing change | Email, direct outreach | sales/outreach |
| Partnership | Press, co-marketing | content, marketing |
| Open source | GitHub, HN, dev Twitter | content/x-posts |

## Launch Readiness Checklist

Before launching, confirm:
- [ ] Landing page / changelog is live and reviewed.
- [ ] Support team is briefed on the new feature.
- [ ] Analytics / tracking events are firing.
- [ ] Legal/compliance approval if required.
- [ ] Customer success has talking points for existing customers.
- [ ] Sales has battlecards if launch affects competitive positioning.

## Launch Principles

- **Launch is a moment, not an event**: Build distribution before launch day.
- **Sequence channels**: Don't announce everywhere at once — stagger for maximum momentum.
- **Measure day-one**: Define the 24-hour and 7-day metrics before launch.
- **Retro always**: Run a 1-week post-launch retrospective to capture what worked.
