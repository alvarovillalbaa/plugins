# Sales Pipeline — Routing Guide

Router for sales pipeline management. Routes to specialist skills.

## Child Skills

| Child | Owns |
|-------|------|
| `revenue-intelligence` | Pipeline analysis, deal signals, risk scoring |
| `revenue-ops` | CRM hygiene, process design, forecasting |
| `growth` | Expansion, retention, and churn-risk work within existing accounts |

## When to Use This Skill Directly

- Running a pipeline review meeting.
- Prioritizing deals for the week.
- Writing deal status updates.
- Forecasting pipeline to revenue.

## Pipeline Stage Definitions

| Stage | Definition | Exit Criteria |
|-------|-----------|---------------|
| Prospecting | Identified target — no contact yet | First meeting booked |
| Discovery | First meeting held | Pain confirmed, budget qualified |
| Evaluation | Active evaluation/POC | Decision criteria agreed |
| Proposal | Proposal sent | Verbal intent to move forward |
| Negotiation | Commercial negotiation | Signed contract |
| Closed Won | Contract signed | Revenue recognized |
| Closed Lost | Deal lost | Loss reason documented |

## Pipeline Health Metrics

- **Pipeline Coverage**: 3× quota required for confidence. Below 2.5× is a risk signal.
- **Stage Conversion**: Track conversion rate at each stage; drop-offs indicate friction.
- **Average Sales Cycle**: Measure by segment; deals >2× average cycle need intervention.
- **Deal Velocity**: Pipeline value × conversion rate / sales cycle length = revenue rate.

## Pipeline Management Rules

- Update deal stage and next step within 24 hours of any customer interaction.
- Every deal needs a documented "next step" with an owner and date.
- Stale deals (no activity in 14 days) are flagged for manager review.
- Loss reasons are required before closing a deal as lost.
