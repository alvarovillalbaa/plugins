# Sales Collateral Types Reference

Reference for creating and adapting sales collateral: one-pagers, decks, case studies, battlecards, and buyer-facing enablement. Each artifact serves a specific stage and audience — match the format to the job. Use only approved, sourced claims; pull product/positioning facts from repo-local docs. Publishing is human-gated.

## Collateral by funnel stage

| Stage | Buyer question | Collateral |
| --- | --- | --- |
| Awareness | "What is this?" | One-pager, explainer, pitch deck |
| Consideration | "Is it right for me?" | Case studies, comparison/battlecard, ROI calculator, demo script |
| Decision | "Can I justify this?" | Proposal, business case, security/trust doc, pricing one-pager |
| Internal selling | "How do I sell this up?" | Champion enablement kit, exec summary, mutual action plan |

## One-pager

A single-page, scannable overview. The most-used asset.
- **Structure**: headline value prop → problem → solution → 3 key benefits → proof (logos/stat/quote) → CTA.
- **Rules**: one job per one-pager (product, use case, or persona — not all three). Visual, skimmable, benefit-led (outcomes, not feature lists). A buyer should get the gist in 30 seconds.
- **Variants**: product one-pager, use-case one-pager, persona one-pager, pricing one-pager.

## Pitch / sales deck

The narrative walkthrough for a meeting.
- **Arc**: hook → the problem/status-quo pain → the stakes (cost of inaction) → your solution → how it works → proof (cases, results) → pricing/packaging → next steps.
- **Rules**: one idea per slide, minimal text (it supports the talk, isn't the script), customer's world before your product, story over feature tour. Leave-behind version can carry more text than the presented version.
- Route visual production to `marketing` slides if needed.

## Case study

Proof that it works for someone like the buyer.
- **Structure**: customer + context → challenge → solution → **quantified results** → quote. The classic Challenge–Solution–Result arc.
- **Rules**: real, approved numbers (X% improvement, $ saved, time reduced); a named, relatable customer; specific before/after. A case study without a metric is a testimonial, not a case study.
- **Variants**: full case study, one-paragraph proof point, logo+stat slide, quote card. (Repurpose via `marketing`.)

## Battlecard

Internal enablement for competitive deals.
- **Structure (per competitor)**: their positioning → where we win → where they win (be honest) → landmines to set → objection handles → trap-setting questions → proof points.
- **Rules**: honest about competitor strengths (reps lose trust in cards that pretend the competitor is bad at everything); concise and scannable mid-call; factual, not disparaging (legal risk — keep claims sourced). Internal-only.

## Proposal / business case

The decision-stage justification document.
- **Includes**: recap of buyer's goals/pain, proposed solution scope, expected outcomes/ROI, pricing and terms, timeline, success criteria, next steps.
- **Rules**: mirror the buyer's stated language and goals; quantify ROI/TCO with their numbers; make the "yes" easy (clear scope, clear price, clear next step). Pricing/terms require approval and `finances` coordination.

## ROI / business-value tools

- Calculators or value models that translate features into the buyer's money.
- Use the buyer's own inputs (volumes, costs, current spend); show the math (auditable, not a black box).
- Conservative assumptions build more trust than aggressive ones.

## Security / trust collateral

- Security overview, compliance certifications, data-handling FAQ, DPA.
- Decision-stage unblockers — answer the "is it safe/compliant?" objection. Verify every claim with the relevant owner; never overstate compliance posture.

## Champion enablement kit

Helps your internal advocate sell up.
- Exec summary, internal-pitch deck, ROI one-pager, FAQ for their stakeholders, mutual action plan.
- Designed for the champion to forward without you in the room — self-explanatory and credible.

## Quality gates (all collateral)

- **Approved claims only** — no fabricated customers, metrics, capabilities, or compliance statements. Mark placeholders for SME/legal review.
- **Benefit-led** — outcomes the buyer cares about, not feature inventories.
- **Audience-matched** — exec vs. practitioner vs. procurement read differently; tailor.
- **On-brand voice** — pull from voice/positioning docs; route polish to `marketing`/`humanizing`.
- **Current** — collateral drifts as product/pricing change; flag stale assets.
- **Human-gated** — present drafts; a human approves and sends. Pricing/terms need `finances` sign-off.
